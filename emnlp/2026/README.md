- 按包含赛道后缀的 Paper ID 去重，并核对论文链接唯一性；区分主会、Industry、TACL 与 CL。
- TACL/CL 为在 EMNLP 报告的期刊论文，不计入主会 462 篇；期刊发表年份可能早于 2026 年。
- 单独标为 Virtual Pres、Poster、Demo、Not Presenting 等的记录不纳入本名单；不含 Workshop。
- 论文元数据来自 [ACL Anthology](https://aclanthology.org/events/emnlp-2026/)、其官方期刊 XML、出版商注册的 Crossref 元数据及作者 arXiv 预印本；逐条来源和匹配方法保存在 JSON。
- 509 篇链接到 ACL Anthology，4 篇链接到出版商 DOI，3 篇以明确标注的预印本补充；每篇提供 PDF 链接。
- 名单保留日程原标题；正式发表标题存在差异时，另存 `publication_title`。报告人不等同于完整作者名单，二者分别记录。
