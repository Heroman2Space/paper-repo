## 数据来源与统计口径

- 数据快照日期：**2026-11-02**。
- 来源：[NeurIPS 官方论文数据](https://neurips.cc/static/virtual/data/neurips-2026-orals-posters.json)。
- 筛选：`decision` 为 `Accept (oral)`，忽略大小写。
- 去重：按 OpenReview 论文链接合并同一篇论文的不同展示记录。
- 范围：主赛道、评测与数据集赛道、立场论文赛道；不含 Workshop。
- 本名单是当前官网公开数据的筛选结果，**不代表最终录用总数**；官网后续可能调整。
- [结构化数据](orals.json)：包含标题、作者、赛道、OpenReview 链接、官网链接和来源校验值。
