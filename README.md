## 目录约定

每届会议使用 `会议小写名/年份/` 目录，例如 `neurips/2026/`。后续新增年份时沿用相同结构。

- `README.md`：可直接阅读的论文名单、赛道分类、统计口径和来源。
- `orals.json`：论文标题、作者、赛道、OpenReview / 官方链接及快照元数据；可用时补充 PDF 链接与 Oral 认定证据。

## 收录原则

- 以会议官网或官方 OpenReview 的 Oral 标记为依据。
- 按稳定的论文标识去重，避免将多个会场或展示记录重复计数。
- 分开记录主赛道、数据集与评测、立场论文等赛道；Workshop 单独整理。
- 每批数据注明快照日期、来源和筛选方法；公开名单的数量不直接作为最终录用总数。
- 保留论文原始英文标题，优先提供官方论文页面和 OpenReview 链接。
- 目前收录论文索引与元数据，不包含 PDF 正文。后续的代码链接、中文摘要和阅读笔记可按需补充。
